## Projects

### [Agentic AI patterns](https://github.com/morrimoz/agentic-ai-patterns)

An invoice investigation application built from nine inspectable patterns. It reads an accounting ledger through MCP, retrieves policy, proposes a credit, waits for review and verifies the resulting entry. It recovers after a worker loses the response following an accounting commit.

- Python, LangGraph, FastAPI, SQLite and MCP.
- Durable approvals, typed tools, retrieval evals and execution recovery.
- Runs locally without API credentials. Includes tests and a repeatable walkthrough.
